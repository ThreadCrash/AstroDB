AstroDB is a local SQL database with a desktop browser.
Store data, run queries, and work directly with your files.

Build AstroDB ↗

SQL, with files.

Read CSV or Parquet directly in a query. Use joins, aggregates, and window functions without importing your dataset first.

Database files stay on disk. The engine runs inside the application.

Query a CSV file
SELECT category, SUM(amount) AS total
FROM read_csv('sales.csv')
GROUP BY category
ORDER BY total DESC;
