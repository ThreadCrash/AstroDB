# Third-party components

AstroDB is an independent workspace, not a new database engine.

- DuckDB is used as a dependency under its MIT license. Copyright and license notices remain with its distribution. Source: https://github.com/duckdb/duckdb
- SQLite is supplied by Python's sqlite3 module. SQLite is public domain; Python has its own license. Source: https://sqlite.org/
- DB Browser for SQLite is not included in this release. The supplied fork is a potential future desktop integration, not a SQL engine. Any incorporation must retain its applicable licenses and notices.
- The website is an original implementation inspired by the supplied DuckDB layout. No DuckDB logos or website assets are bundled.
